# 출시 노트 (한국어)

`release-notes.md`의 한국어판. 영어가 원본이므로 문구가 바뀌면 영어를 먼저
고치고 여기로 옮깁니다.

**Play는 언어당 500자 제한**이고, 한글은 같은 내용을 영어보다 짧게 쓸 수 있어
여유가 있는 편입니다. 그래도 짧은 쪽을 기준으로 씁니다.

지켜야 할 두 가지는 영어판과 같습니다:

- **저장소가 아니라 사용자에게 무엇이 바뀌었는지** 씁니다. 어떤 프로바이더를
  리팩터링했는지는 스토어 업데이트를 읽는 사람과 상관없습니다.
- **출시되지 않은 것은 적지 않습니다.** 아직 열리지 않은 구독 기능이나 로드맵
  항목은 여기 등장하지 않습니다.

## 1.0.0 — 첫 출시

**Play** (500자 제한):

```
LabFox는 GitLab을 휴대폰으로 가져옵니다.

• 머지 리퀘스트를 승인 현황과 토론까지 전문으로 확인
• diff를 실제 줄 번호와 함께 파일별로 확인
• 승인, 머지, 댓글 작성
• 파이프라인 확인, 잡 로그를 색상 그대로 열람, 재시도와 취소
• 이슈, 할 일 목록, 검색, 저장소 탐색

gitlab.com과 자체 호스팅 인스턴스 모두 동일하게 동작합니다. 토큰은 기기
키체인에만 보관되며 LabFox 계정도 서버도 없습니다.

오픈소스, Apache-2.0.
```

**App Store**:

```
LabFox 첫 출시입니다.

지하철에서 머지 리퀘스트를 리뷰하고, 자리에 앉기 전에 파이프라인이 왜 빨간지
확인하세요.

• 머지 리퀘스트 전문 — 설명, 라벨, 승인 현황, 토론
• diff를 실제 줄 번호와 변경 라인 강조로, 파일별로
• 승인, 머지, 댓글 작성
• 파이프라인 상태를 한눈에, 잡 로그는 러너가 출력한 색상 그대로
• 실패한 잡 재시도, 취소, 수동 잡 실행
• 이슈, 할 일 목록, 검색, 저장소, 브랜치, 커밋

레이아웃은 기기가 아니라 화면 크기를 따릅니다. 휴대폰에서는 하나에 집중하는
단일 화면, 태블릿에서는 내비게이션 레일과 머지 리퀘스트 스무 개를 볼 공간.

gitlab.com과 자체 호스팅이 똑같이 동작합니다. 토큰은 기기 키체인에 보관되며,
여러분의 GitLab과 앱 사이에 LabFox 계정도 서버도 없습니다.

Apache-2.0 오픈소스: github.com/theorvane/labfox
```
