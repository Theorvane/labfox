# 스토어 등록 문구 (한국어)

`listing.md`의 한국어판. 영어가 원본이고, 이 파일은 번역입니다 — 문구가 바뀌면
영어를 먼저 고치고 여기로 옮깁니다.

번역이지 직역은 아닙니다. 개발자가 실제로 쓰는 말을 씁니다: merge request는
"머지 리퀘스트"가 아니라 **MR**, pipeline은 "관로"가 아니라 **파이프라인**입니다.
GitLab UI 용어(이슈, 머지 리퀘스트, 파이프라인, 잡)는 그대로 둡니다.

지켜야 할 두 가지는 영어판과 같습니다:

- **GitLab이 보증한다는 인상을 주지 않습니다.** 비공식 클라이언트 고지를 넣습니다.
- **만들지 않은 것을 약속하지 않습니다.** 푸시 알림과 오프라인 열람은 로드맵
  항목이라 구독 문구에만 등장합니다.

```
LabFox
```

```
GitLab 머지 리퀘스트와 CI
```

```
GitLab 머지 리퀘스트를 리뷰하고 파이프라인과 잡 로그를 확인하세요.
```

## 전체 설명

```
지하철에서 머지 리퀘스트를 리뷰하고, 자리에 앉기 전에 파이프라인이 왜 빨간지
확인하세요. LabFox는 매일 만지는 GitLab을 휴대폰으로 가져옵니다. 웹 UI를
확대하고 스크롤할 필요 없이.

할 수 있는 일

• 머지 리퀘스트를 설명, 라벨, 승인 현황, 토론까지 읽을 수 있는 형태로 확인
• diff를 실제 줄 번호와 변경 라인 강조로, 파일별로 확인
• 승인, 머지, 댓글 작성
• 파이프라인 진행 상황과 성공·실패·진행 중 상태를 한눈에
• 잡 로그를 러너가 출력한 색상 그대로 전문 확인
• 실패한 잡 재시도, 취소, 수동 잡 실행
• 이슈, 할 일 목록, 프로젝트 전체 검색
• 저장소, 브랜치, 커밋, 파일 탐색

실제 작업 방식에 맞춘 화면

레이아웃은 기기가 아니라 화면 크기를 따릅니다. 휴대폰에서는 하나에 집중하는
단일 화면, 태블릿에서는 내비게이션 레일과 머지 리퀘스트 스무 개를 한 번에 볼
공간. 같은 앱, 같은 기능입니다.

자체 호스팅도 동등하게

gitlab.com이든 회사 인스턴스든 똑같이 동작합니다. 개인 액세스 토큰이나
OAuth로 로그인하세요.

자격 증명은 기기에만

토큰은 기기 키체인에 보관되며 평문으로도, 로그에도 남지 않습니다. LabFox
계정도 LabFox 서버도 없습니다. 앱이 여러분의 GitLab과 직접 통신합니다.

오픈소스

LabFox는 Apache-2.0 라이선스입니다. 코드를 보고, 이슈를 남기고, 패치를
보내주세요: github.com/theorvane/labfox

—

LabFox는 비공식 서드파티 클라이언트입니다. GitLab Inc.와 제휴 관계가 없으며
GitLab Inc.의 보증이나 인증을 받지 않았습니다. "GitLab"은 GitLab Inc.의
상표입니다.
```

## 구독 문구

`.agents/docs/monetization.md` §2와 맞춰 둡니다. 무료·유료 경계가 바뀌면
영어판과 함께 이 문구도 바뀝니다.

```
LabFox는 무료로 내려받아 읽는 데는 계속 무료입니다. 계정 하나로 모든
프로젝트, 이슈, 머지 리퀘스트, diff, 파이프라인, 잡 로그를 볼 수 있습니다.

구독하면 일을 끝내는 동작이 열립니다:

• 승인과 머지
• 재시도, 취소, 수동 잡 실행
• 계정 여러 개 — 자체 호스팅 인스턴스 여러 곳 포함
• 즐겨찾기와 저장된 검색 무제한

구독은 해지 전까지 자동 갱신되며 스토어 계정에서 관리합니다. 데스크톱 빌드는
모든 기능이 무료입니다.
```

## 번역하며 판단한 것

**"Review a merge request on the train"** — "기차에서"로 직역하면 한국에서는
어색합니다. 출퇴근길에 읽는다는 뜻이므로 "지하철에서"로 옮겼습니다.

**"first-class citizen"** — 직역하면 뜻이 전달되지 않습니다. "동등하게"로
풀었습니다.

**"pinch and scroll"** — "꼬집기"가 아니라 "확대하고 스크롤"입니다.

**부제**는 30자 제한이 한글에서 더 빡빡합니다. "GitLab 머지 리퀘스트와 CI"가
14자로, 영어판(26자)보다 여유가 있습니다.
